# HTML 可视化编辑器

一个纯静态、零依赖、离线可用的在线 HTML 可视化编辑器：左侧编辑源码，右侧实时预览，直接在预览中点击元素即可进行可视化编辑，完成后一键导出完整 HTML 文件。

**在线使用：<https://monster3456.github.io/html-editor/>**

## 功能特性

- **两种打开方式**：单个 HTML 文件，或整个项目文件夹（HTML + CSS + 图片）；多个页面时可选要编辑的那一个，切换页面时编辑内容自动保留
- **元素树面板**：左侧展示页面 DOM 结构（标签 + id/class + 文字摘要），点击树节点选中元素并与预览/属性面板三方联动，悬停即在预览中高亮，支持**拖拽调整元素顺序**（可拖入容器内部或前后插入）
- **插入新元素**：工具栏"插入"菜单或预览中**右键菜单**，一键插入标题、段落、图片（自带占位图）、按钮、链接、分隔线、容器、列表、引用块、视频等 11 种元素，新元素自动选中
- **右键菜单**：在预览中右键任意元素，快速复制、删除、移动，并可直接插入新元素
- **左右分栏实时同步**：左侧源码（语法高亮 + 行号），右侧实时预览；两侧任一修改即时互通
- **点击即选**：在预览中单击任意元素选中，悬停显示轮廓提示
- **可视化属性面板**：
  - 通用操作：删除、复制、上移/下移、隐藏/显示、清除内联样式
  - 文本：面板替换文字（保留嵌套子元素），或**双击预览中的元素直接内联编辑**
  - 尺寸与间距：实时显示实际渲染尺寸，宽/高/内边距/外边距/圆角，一键清除
  - 字体：字号（滑杆 + 数值）、字重、对齐方式
  - 颜色：文字颜色、背景颜色（可清除）
  - 透明度：0–100% 滑杆
  - 边框：宽度 / 样式 / 颜色
  - 图片：替换图片地址、上传本地图片（转为 data URI 内嵌）、修改 alt
  - 链接：修改 href 与打开方式
- **设备宽度预览**：一键切换 375px（手机）/ 768px（平板）/ 全宽，检验响应式布局
- **查找替换**：Ctrl+F 在源码中查找（计数、回车跳转、逐个/全部替换）
- **草稿自动保存**：编辑内容每 2 秒自动存入浏览器 IndexedDB，下次打开时欢迎页提供"恢复上次编辑"，即使误关页面也不丢工作
- **导出自包含文件**：项目中的 CSS 与本地图片在导出时自动内联进 HTML，生成一个随处可用的单文件
- **撤销 / 重做**：完整历史记录，快捷键支持
- **其他**：新窗口预览、可拖拽分栏（位置记忆）、元素树折叠记忆、非 UTF-8 编码自动识别（如 GBK）、修改未导出时关闭页面提醒

## 快速开始

**在线版**：直接访问 <https://monster3456.github.io/html-editor/>

**本地运行**（任选其一）：

```bash
# 方式一：任意静态服务器
python -m http.server 8000
# 然后打开 http://localhost:8000/
```

方式二：直接双击 `index.html` 用浏览器打开（无需服务器，同样可用）。

## 使用说明

1. 打开本地 HTML 文件或项目文件夹（也可直接拖入窗口），或使用内置示例
2. 在右侧预览中**单击**元素选中，通过浮动属性面板编辑；**双击**可直接修改文字
3. 左侧源码可随时直接编辑，约半秒后预览自动刷新
4. 点击 **导出 HTML**（或 Ctrl+S）保存编辑结果——项目引用的 CSS 与图片会自动内联

## 快捷键

| 快捷键 | 功能 |
|---|---|
| Ctrl+Z / Ctrl+Y | 撤销 / 重做（代码框内为原生撤销） |
| Ctrl+S | 导出 HTML |
| Ctrl+O | 打开文件 |
| Ctrl+F | 查找 / 替换（Enter 下一处，Shift+Enter 上一处，Esc 关闭） |
| Tab | 代码中插入两个空格 |
| Esc | 结束内联编辑 / 关闭菜单 / 取消选中 |

## 技术实现

纯原生 HTML/CSS/JavaScript，无任何框架与外部依赖，无构建步骤：

- 预览使用无 `src` 的同源 iframe（about:blank 继承父页面 origin）+ `document.write` 渲染，因此 **file:// 直接打开也能完整工作**
- iframe 设置 `sandbox="allow-same-origin"`：页面脚本默认**不执行但原样保留**，导出的 HTML 中脚本一字不丢；需要运行页面脚本时可在工具栏开启（会重建预览）
- 编辑器注入的样式与选中标记在序列化时全部剥离，导出结果干净
- 单一数据源（HTML 字符串）驱动两侧视图，程序化赋值结构性避免同步回环

## 已知限制

- 预览中项目外的相对路径资源可能无法显示；**导出文件不受影响**（会尝试内联本地文件，其余原样保留）
- 页面脚本默认禁用；开启后脚本可能干扰编辑（如跳转、改写 DOM）
- 在预览中做过编辑后，源码会被浏览器规范化（补全隐含的 `<html>/<head>/<body>` 标签、属性引号统一等），语义不变
- frameset 页面不支持可视化编辑，但源码编辑与导出正常
- 插入的"视频"元素不带默认片源，插入后请在源代码中为 `<video>` 填写视频地址
- 草稿保存在浏览器本地（IndexedDB，单文件上限约 10MB）；清除浏览器数据会同时清除草稿
